# Weather App (React Native)

Welcome to the Weather App! 🌦️

This app provides weather forecasts, and it's built using React Native. Currently, it is in progress and features are being added in future updates. 

## Features (Coming Soon)
- 7-day forecast
- Detailed weather conditions (wind speed, humidity, etc.)

## Upcoming Updates
- Improved UI/UX
- Push notifications for weather updates
- Support for multiple locations
- Weather map view
- Dark Mode option
